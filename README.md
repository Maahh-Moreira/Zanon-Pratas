# Zanon Joias – Sistema SaaS com MySQL

Sistema de gestão para joalheria: produtos, estoque, vendas, clientes, compras e gastos.

## Funcionalidades

- Cadastro de usuário (nome, e-mail, senha + confirmar senha)
- Login com e-mail e senha
- Produtos (cadastro, edição, exclusão, estoque)
- Vendas (baixa automática de estoque)
- Clientes
- Compras / entrada de estoque
- Gastos
- Dashboard com totais
